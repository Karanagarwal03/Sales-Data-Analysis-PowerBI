# 📊 Sales Data Analysis Dashboard (Power BI)

## 🚀 Project Overview
This project is an interactive Sales Data Analysis Dashboard built using Power BI to analyze business performance, identify trends, and generate actionable insights.

The dashboard enables stakeholders to:
- Track sales performance over time
- Analyze regional sales distribution
- Understand customer purchasing behavior
- Evaluate profitability across products and categories

---

## 🛠️ Tools & Technologies
- Power BI  
- Power Query (ETL)  
- DAX (Data Analysis Expressions)  
- Data Modeling  

---

## 📁 Dataset
- Source: Sample Dataset  
- The dataset includes:
  - Sales transactions  
  - Customer information  
  - Regional data  
  - Product details

## 📌 Key Features
- Interactive filters and slicers  
- KPI tracking (Total Sales, Profit, Revenue)  
- Time-based trend analysis  
- Region-wise performance breakdown  
- Drill-down capabilities for deeper insights  

---

## 📈 Key Insights
- Identified top-performing regions contributing to overall revenue  
- Observed sales trends across different time periods  
- Highlighted variation in profit margins across product categories  

---

## 🧩 Data Processing
- Data cleaning and transformation using Power Query  
- Handling missing values and inconsistencies  
- Data modeling with relationships  
- Creation of calculated measures using DAX

## 📊 How to Use

2. Open it in Power BI Desktop
