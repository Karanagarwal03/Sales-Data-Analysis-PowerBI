# 📊 Sales Data Analysis Dashboard (Power BI)

## 🚀 Project Overview
This project is an interactive Sales Data Analysis Dashboard built using Power BI to analyze business performance, identify trends, and generate actionable insights.

The dashboard enables stakeholders to:
- Track sales performance over time
- Analyze regional sales distribution
- Understand customer purchasing behavior
- Evaluate profitability across products and categories

---

## 🛠️ Tools & Technologies
- Power BI  
- Power Query (ETL)  
- DAX (Data Analysis Expressions)  
- Data Modeling  

---

- Source: Sample Dataset
